# Contributing

Thank you for considering contributing to `nordkit/wiretap`!

## Setup

```bash
composer install
```

## Running Tests

```bash
vendor/bin/pest
```

## Code Style

This project uses [Laravel Pint](https://laravel.com/docs/pint). Before submitting a PR, run:

```bash
vendor/bin/pint
```

## Pull Requests

- Open an issue first to discuss significant changes.
- Every change must be covered by a new or updated test.
- Ensure `vendor/bin/pest` and `vendor/bin/pint --test` both pass before submitting.
- Follow [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) conventions when updating `CHANGELOG.md`.
